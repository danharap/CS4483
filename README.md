# CS4483 — Wave Game (Unity)

## Local accounts & saves (JSON)

The main menu includes **sign up / sign in**, up to **3 saves per account**, load, delete, and autosync — all stored in **`local_accounts.json`** under the OS user data folder (see **`Docs/LocalAccounts.md`**). No cloud account or external database setup.

An empty starter file is in **`Assets/StreamingAssets/DefaultLocalAccounts/accounts.json`** and is copied on first run if no database exists yet.

## Local development

Open the project in Unity and run **CS4483 → SETUP EVERYTHING** (or your team’s equivalent) to wire scenes and prefabs.
